Yellow/Brown Ceramic Capacitors (MLCC) PC / C မလိုပါ (ဖြုတ်ထားပါ) B+ 19V Rail တွင် Parallel (ပြိုင်ဆက်) ဆက်ထားသဖြင့် **Short ဖြစ်နေသော အတုံးကို ခွာထုတ်လိုက်ရုံဖြင့် 19V Short ချက်ချင်း ပျောက်ပြီး ပါဝါပြန်လာပါသည်**။ အစားထိုးရန် မလိုအပ်ပါ။
Input MOSFETs (First & Second Gate) PQ1, PQ2 အစားထိုးရန် လိုအပ်သည် Drain-to-Source Short သို့မဟုတ် Gate ပေါက်နေပါက 19V လမ်းကြောင်း ပွင့်မည်မဟုတ်ပါ။ Specification တူညီသော N-Channel 30V MOSFET အသစ် အစားထိုးရပါမည်။
PWM / Charging Control IC U / PU အစားထိုးရန် လိုအပ်သည် IC ၏ VCC သို့မဟုတ် ACDET Pin Internal Short ဖြစ်ပါက အစားထိုးရပါမည်။ Part Number တူညီသော IC သို့မဟုတ် Board အဟောင်းမှ လဲလှယ်ရပါမည်။
Power Inductors / Coils PL လဲရန် မလိုပါ Coil များသည် Short ဖြစ်ခဲပါသည်။ Short Line မည်သည့်အကန့်တွင် ရှိသည်ကို Circuit အကန့်ခွဲ စစ်ဆေးရန်အတွက်သာ Coil ကို ဖြုတ်၍ တိုင်းတာသည်။

DC Bench Power Supply Voltage Injection Technique (Short ရှာနည်း)

  1. Voltage တန်ဖိုး သတ်မှတ်ခြင်း: Power Supply Voltage ကို **1.0V မှ 1.5V ထက် ပိုမပေးရပါ** (Ampere ကို 3A မှ 5A ထားပါ)။ Voltage လွန်ပါက CPU/PCH ပျက်စီးနိုင်သည်။
  2. Voltage ထည့်သွင်းခြင်း: Power Supply ၏ Red (+ Probe) ကို B+ Rail (PQ2 Drain သို့မဟုတ် Short ကျနေသော Capacitor Plus Pad) တွင် သဟဇာတဖြစ်အောင် ဂဟေဆက်ပါ၊ Black (- Probe) ကို Board GND တွင် ချိတ်ပါ။
  3. Alcohol Test / Thermal Inspection: Board ပေါ်ရှိ SMD Ceramic Capacitors များပေါ်သို့ **Isopropyl Alcohol (IPA)** ဖြန်းပေးပါ။ Short ကျနေသော အတုံးသည် ချက်ချင်း ပူလာပြီး Alcohol အငွေ့ပျံသွားပါမည်။
  4. ပြုပြင်ခြင်း: ထိုပူလာသော Capacitor အတုံးကို Hot Air Station ဖြင့် ခွာထုတ်လိုက်ပါ၊ B+ Short ချက်ချင်း ပျောက်သွားပါမည်။
1. No Power (ပါဝါ လုံးဝမလာခြင်း)
  • DC Jack အဝင် 19V တိုင်းပါ ( Adapter အဆင်ပြေရမည်)။
  • PQ1, PQ2 Input MOSFET Gate Voltage (24V ACDRV) ထွက်မထွက် စစ်ပါ။
  • 3V/5V Standby PWM IC ၏ VREG3 (3.3V) & VREG5 (5V) LDO စစ်ပါ။
  • EC IC (IT8587) VCC 3.3V နှင့် Power Button 3.3V -> 0V Pulse စစ်ပါ။
2. RAM Detection Failure (3 Beeps / No Display)
  • DDR4 Main VDD Voltage **1.2V** Coil တွင် ထွက်မထွက် စစ်ပါ။
  • DDR4 VTT Bus Termination Voltage **0.6V** စစ်ပါ။
  • SPD Pin 255/256 တွင် SMBus Clock & Data **3.3V** တိုင်းပါ။
  • RAM Slot Pin များ ဖုန်တက်/ဂျီးကပ်နေပါက Contact Cleaner ဖြင့် ဆေးပါ။
3. No Display / Black Screen (စက်ပွင့်ပြီး ရုပ်မလာ)
  • CPU VCORE Coil တွင် **0.8V - 1.0V** ထွက်မထွက် စစ်ပါ။
  • BIOS Chip Pin 8 VCC **3.3V** နှင့် Pin 1 CS# Signals တိုင်းပါ။
  • BIOS Firmware Bin File ပျက်စီးပါက BIOS Programmer ဖြင့် Flash ပြန်လုပ်ပါ။
  • PCH PLTRST# Reset Signal **3.3V** ရှိမရှိ စစ်ပါ။
4. Continuous High-Speed Fan Spin
  • CPU Thermal NTC Sensor Resistor line တွင် Voltage မှားနေခြင်း။
  • Fan PWM Control Circuit (MOSFET/Transistor) Short ဖြစ်နေခြင်း။
  • EC Super I/O IC Firmware ပျက်နေသဖြင့် Fan Control Signal အမြဲ Max ပေးနေခြင်း။
5. Auto Power-On when Plugged In
  • RTC 3V Battery Voltage **2.8V အောက်** နည်းနေပါက Auto-On ဖြစ်တတ်ပါသည်။
  • Deep S5 State Switch MOSFET ပေါက်နေခြင်း။
  • BIOS RTC Clear CMOS Settings ပျက်နေခြင်း။
6. Boot Failure / Stuck at Logo
  • NVMe / SATA +3.3V & +5V Power Rail Voltage ပြုတ်ကျနေခြင်း။
  • PCH PCIe Clock Generator Signal မငြိမ်ခြင်း။
  • Storage Controller / PCH Chip အပူလွန်ကဲနေခြင်း။
